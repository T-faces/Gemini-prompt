# Gemini-lab

🇺🇸 English 
Gemini-lab: Simple Image Prompting Interface
This is a simple Gemini project—an interface that allows you to detect and generate a prompt from an uploaded image. Its use is straightforward: simply upload your image, and the system will automatically generate the corresponding prompt.



🇮🇩 Indonesian 
Gemini-lab: Proyek Sederhana
Ini adalah antarmuka yang memungkinkan Anda melakukan deteksi dari sebuah gambar yang diunggah. Penggunaannya pun sangat sederhana: cukup unggah gambar Anda, dan sistem akan menghasilkan prompt (deskripsi) dari gambar tersebut.
